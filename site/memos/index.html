TabRetake / Memos

Write a memo and find it again

Write in the real rich-text editor, save the memo, open Search, find it by a phrase, then focus the camera on the matching content.

Maintainer-run reproduction using the unmodified Memos 26.11.2 official release and fictional local data. Upstream development and branding belong to the project authors. External adoption is tracked separately.

Download the story

Install TabRetake

npm install --global git+https://github.com/gnawbit/tabretake.git#v0.4.0
tabretake setup

Start a local instance

These Windows PowerShell commands were tested with the x64 official release. Run them in a new disposable directory. Other platforms can use the matching upstream release.

Invoke-WebRequest https://github.com/usememos/memos/releases/download/26.11.2/memos_26.11.2_windows_amd64.zip -OutFile app.zip
if ((Get-FileHash app.zip -Algorithm SHA256).Hash.ToLower() -ne 'b7c8267e637db74c75f7caa00f60083c53d1f660a8c088e6f09eac1aa62eeb4f') { throw 'Checksum mismatch' }
Expand-Archive app.zip -DestinationPath app
Set-Location app
New-Item -ItemType Directory -Force data
./memos.exe --addr 127.0.0.1 --port 4189 --data ./data

Create a local account, select English and dismiss the welcome guide before saving your login state. Use fictional memo content. The story preserves the default private visibility.

Record the story

Keep the app running. Open a second terminal in your story directory. The login command opens a browser. Sign in, dismiss onboarding, then press Enter in the terminal to save auth.json locally.

tabretake plan --url http://127.0.0.1:4189 --login
tabretake validate --config memos-story.json --json
tabretake record --config memos-story.json --storage-state auth.json --out demo-memos --json
tabretake render --config demo-memos/record.json --vertical --json

Keep auth.json local and add it to your project's ignore list. The story and application may create real entries in this disposable instance.

Preview and retake

tabretake preview --config memos-story.json --storage-state auth.json

Preview executes the same app changes. Remove the previously created demo entry before repeating the same story, or use a unique name consistently across its steps. Replace every occurrence of “check keyboard navigation” with “verify mobile layout” in a copy of the story. This updates both the memo content and the search phrase.

Observed result

Windows verification on 2026-11-23 produced two takes lasting 11.8 and 11.1 seconds. Both were rendered into landscape and portrait MP4, GIF and posters. The second take reused the same step structure with new fictional content. The application and saved login state were reused.

Inspect your rendered output at its intended viewing size. The desktop layout retains small text in the portrait frame. The checked flow uses English UI labels and the pinned upstream version.

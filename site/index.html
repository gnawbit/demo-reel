demo-reel by gnawbit turns web app flows or existing screen recordings into README GIFs, MP4s and PNG posters in 16:9 and 9:16. Add click zooms and captions locally, then re-run editable JSON steps after UI changes.

npm install --global git+https://github.com/gnawbit/demo-reel.git#v0.3.3 demo-reel capabilities --json demo-reel doctor --json

CLI: Node 20.9+ and Git. Windows, macOS and Linux. FFmpeg and ffprobe are included. Output videos have no audio. Installation details.

Add the Agent Skill

npx skills@1.9.0 add gnawbit/demo-reel@v0.3.3 --skill demo-reel

Run in your target project after installing the CLI. Skills CLI needs Node 22.20+. Client selection and Claude Code plugin.

TabRetake by gnawbit turns web app flows or existing screen recordings into README GIFs, MP4s and PNG posters in 16:9 and 9:16. Add click zooms and captions locally, then re-run editable JSON steps after UI changes.

npm install --global @gnawbit/tabretake@0.5.0 tabretake demo --preset daylight

CLI: Node 20.9+ on Windows, macOS & Linux. Uses local Chrome/Edge automatically or pinned Chromium via tabretake setup. FFmpeg and ffprobe are included. Output videos have no audio. Installation details.

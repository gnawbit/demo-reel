TabRetake / Vikunja

Create a task and move it across a real Kanban board

Create a task in Inbox, switch to Kanban, drag it into Doing, wait for the card in its destination column, then focus the camera on the result.

Maintainer-run reproduction using the unmodified Vikunja v2.8.0 official release and fictional local data. Upstream development and branding belong to the project authors. External adoption is tracked separately.

Download the story

Install TabRetake

npm install --global @gnawbit/tabretake@0.4.2
tabretake setup

Start a local instance

These Windows PowerShell commands were tested with the x64 official release. Run them in a new disposable directory. Other platforms can use the matching upstream release.

Invoke-WebRequest https://github.com/go-vikunja/vikunja/releases/download/v2.8.0/vikunja-v2.8.0-windows-4.0-amd64.exe-full.zip -OutFile app.zip
if ((Get-FileHash app.zip -Algorithm SHA256).Hash.ToLower() -ne 'a65637c960b5c88fc3be3fa26a1a96626285e32a0d6abdefb869c8e3c26096db') { throw 'Checksum mismatch' }
Expand-Archive app.zip -DestinationPath app
Set-Location app
@'
service:
  interface: "127.0.0.1:4188"
  publicurl: "http://127.0.0.1:4188/"
database:
  type: "sqlite"
  path: "./vikunja.db"
'@ | Set-Content -Encoding utf8 config.yml
./vikunja-v2.8.0-windows-4.0-amd64.exe

Create a local account, select English in your account settings, and use the default Inbox with To-Do, Doing and Done buckets. This story expects a fresh instance with Inbox project 1 and list view 1. Adjust its URL if your project uses another ID.

Record the story

Keep the app running. Open a second terminal in your story directory. The login command opens a browser. Sign in, dismiss onboarding, then press Enter in the terminal to save auth.json locally.

tabretake plan --url http://127.0.0.1:4188 --login
tabretake validate --config vikunja-story.json --json
tabretake record --config vikunja-story.json --storage-state auth.json --out demo-vikunja --json
tabretake render --config demo-vikunja/record.json --vertical --json

Keep auth.json local and add it to your project's ignore list. The story and application may create real entries in this disposable instance.

Preview and retake

tabretake preview --config vikunja-story.json --storage-state auth.json

Preview executes the same app changes. Remove the previously created demo entry before repeating the same story, or use a unique name consistently across its steps. Replace every occurrence of “Draft launch announcement” with “Review launch checklist” in a copy of the story. Keep the 1280 × 800 viewport because the drag uses a 316-pixel horizontal offset. The waitFor step verifies the destination column.

Observed result

Windows verification on 2026-11-23 produced two takes lasting 9.0 and 8.9 seconds. Both were rendered into landscape and portrait MP4, GIF and posters. The second take reused the same step structure with new fictional content. The application and saved login state were reused.

Inspect your rendered output at its intended viewing size. The desktop layout retains small text in the portrait frame. The checked flow uses English UI labels and the pinned upstream version.
